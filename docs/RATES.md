# Курсы — этап 3

## Основные источники и даты

**Фиат:** HTTPS `www.cbr.ru/scripts/XML_daily.asp?date_req=ДД/ММ/ГГГГ`.
В запрос уходит именно дата слепка, в том числе выходной или праздник. Сам ЦБ
возвращает действующую таблицу; дата Date из XML сохраняется как начало действия.
Приложение не пытается вычислять банковские выходные, не переносит запрос на
следующий рабочий день и не принимает дату XML позже запрошенной.
Курс одной единицы = Value / Nominal, вся арифметика Decimal.

**BTC/USDT:** CoinGecko, идентификаторы `bitcoin` и `tether`, валюта `rub`.
Прошлые даты — `/api/v3/coins/{id}/history?date=ДД-ММ-ГГГГ&localization=false`,
историческая точка соответствует 00:00 UTC. Сегодня — `/api/v3/simple/price`
с ids, vs_currencies=rub и include_last_updated_at=true. Для текущей цены
сохраняется last_updated_at; цена старше двух часов или из будущего отклоняется.
Речь об оценке в выбранный день, а не о цене конкретной сделки владельца.

Числовые JSON-лексемы сначала сохраняются как строки, затем разбираются Decimal.
Превращения цены в double нет, включая научную запись небольших значений.

## Резерв: утверждён владельцем 2026-11-16

Используется **Kraken Public REST API** (`api.kraken.com`): пары XBTUSD и USDTUSD.
Цена каждой пары умножается на курс USD ЦБ, действующий на выбранную дату.
Для USDT берётся фактическая цена пары, **равенство 1 USDT = 1 USD не предполагается**.
Это один резервный криптоисточник плюс уже используемый ЦБ, без ключей доступа
и без добавления биржевых аккаунтов/личных данных в приложение.

Сегодня: `/0/public/Ticker?pair=...`, последняя цена сделки `c[0]`.
История: `/0/public/OHLC?pair=...&interval=1440&since=...`, где since —
полночь UTC нужной даты **минус 86400 секунд** (API может исключать саму границу).
Из ответа выбирается открытие дневной
свечи именно запрошенной даты UTC. Цена открытия выбрана для согласования с
00:00 UTC CoinGecko; close той же свечи означал бы уже другую временную точку.
Проверяется имя возвращённой пары. Источник показан как «Kraken × USD ЦБ»,
у него также видна дата действующей таблицы USD ЦБ.

**Ограничения резерва:** OHLC Kraken ограничен последними примерно 720 свечами.
Если требуемой даты нет, приложение не подставляет последнюю доступную свечу:
показывает ошибку и оставляет ручной ввод. Пересчёт USD ЦБ — иной способ оценки,
чем прямая RUB-котировка CoinGecko, поэтому результаты могут различаться.
Резерв Kraken × USD ЦБ **утверждён владельцем 2026-11-16** вместе с этапом 3.
На GitHub Codex его не отправляет.

Публичные API и глубина истории CoinGecko могут зависеть от тарифа, лимитов,
доступности и региона. Ни успешный доступ ко всем старым датам, ни отсутствие
HTTP 401/429 не обещаются. При недоступности обоих источников остаётся ручной ввод.

Ссылки для проверки контракта источников на ревью:

- [ЦБ: XML на выбранную дату](https://www.cbr.ru/scripts/XML_daily.asp?date_req=10/01/2026).
- [CoinGecko history](https://docs.coingecko.com/reference/coins-id-history).
- [CoinGecko simple price](https://docs.coingecko.com/reference/simple-price).
- [Kraken OHLC](https://docs.kraken.com/api/docs/rest-api/get-ohlc-data/).
- [Kraken ticker](https://docs.kraken.com/api/docs/rest-api/get-ticker-information/).

Локальные тесты проверяют контракт на **синтетических** образцах, без живых
запросов. Фактическая доступность API с телефона/ПК проверяется при приёмке.

## Кэш и фиксация

`rate_cache`: валюта + запрошенная дата + источник, значение TEXT, effective_at,
fetched_at и метаданные HLC. Исторический кэш используется до явного обновления;
сегодняшний — до 15 минут. Время получения при чтении кэша не заменяется текущим.
Старый кэш v2 без времени получения не используется, пока не обновлён.
Принудительное обновление не выдаёт устаревший кэш за новый ответ при сбое.

Создание слепка автоматически запрашивает курсы; пустой/неполный ответ не теряет
сам черновик. Доступные курсы сохраняются, ошибки видны по валютам, остальные
можно ввести вручную. Добавление валюты и изменение даты черновика обновляют
недостающее. Действующий ручной курс той же даты при этом сохраняется.
Кнопка «Обновить курсы слепка» явно спрашивает разрешение заменить сохранённые,
в том числе ручные курсы. Для зафиксированного слепка замена попадает в аудит.
Слепок сам по себе при открытии автоматически не переоценивается.

В `snapshot_rate` лежат rate_date (дата слепка), effective_at (момент/дата
наблюдения источника) и fetched_at (время получения). Они видны рядом с курсом.
После изменения даты старые курсы другой даты нельзя незаметно использовать:
нужно обновление или ручной ввод. Если слепок изменён, пока шёл запрос, его
запоздавшие курсы не перезаписывают новые данные. При частичном сбое прежние
значения сохраняются и остаются видимыми вместе с ошибкой обновления.

«По сегодняшнему» — отдельная оценка **тех же остатков**. Она читает/пополняет
только rate_cache и не меняет snapshot_rate, суммы или audit_log. При сбое
сегодняшней оценки предлагается вернуться к курсам слепка. Ручной ввод
применяется к курсам слепка, а не выдаётся за сегодняшнюю интернет-котировку.

## Сеть и ограничения

Транспорт принимает только HTTPS к www.cbr.ru, api.coingecko.com, api.kraken.com,
без userinfo и нестандартных портов. Перенаправления отключены, ответ до 2 МиБ,
один запрос — до 10 секунд (соединение до 8). Один повтор через 2 секунды только
для HTTP 429/502/503/504. Ответы с внешними сущностями XML запрещены.
При нескольких валютах обращения последовательны; суммарная загрузка может
занять больше одного таймаута. При закрытии сессии транспорт закрывается.

Передаются только коды валют/активов и календарная дата. Остатки, семейные
части, названия мест, PIN и ключи в запросы не входят. Других сетевых источников,
телеметрии или автоматического обхода ограничений API нет. Android разрешает
INTERNET, незашифрованный HTTP выключен.
