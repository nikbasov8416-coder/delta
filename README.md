# Delta

Личное приложение владельца: слепки остатков, несколько валют у места хранения,
личная и семейная части, история и отчёты. Цели — Android 8+ (minSdk 26) и
Windows 10+ x64. Интерфейс на русском, Material 3, светлая и тёмная темы.

**Этап 1 — каркас.** Экраны являются заглушками; ввод, база реальных данных,
PIN/биометрия, курсы и синхронизация ещё не подключены. Для реальных финансов
эту сборку не использовать.

- [Архитектура и границы этапа](docs/ARCHITECTURE.md).
- [Разработка, генерация drift и тесты](docs/DEVELOPMENT.md).
- [Приватное зеркало GitHub и скачивание APK/Windows ZIP](docs/GITHUB.md).
- [Версии и лицензии всех зависимостей](DEPENDENCIES.md).

Flutter stable 3.50.0 / Dart 3.14.0. Структура: `lib/domain`, `lib/data`, `lib/ui`.
Деньги — Decimal, хранение — TEXT, основа базы — drift + SQLCipher.
В тестах только выдуманные данные. Локальных финансовых файлов и секретов нет.

В самостоятельном репозитории из корня приложения:

```bash
flutter pub get --enforce-lockfile
dart run build_runner build
flutter analyze --no-pub --fatal-infos
flutter test --no-pub
```

На личном сервере — через `tool/flutterw` (см. разработку).
Автосборки настроены в `.github/workflows/build.yml`; публикацию зеркала и
первый запуск Actions выполняет владелец после ревью Claude.
